# HEC-Test-Group-X — Second Brain

A personal knowledge management system organized with Tiago Forte's **PARA** method.

## Structure

- **[Inbox/](Inbox/)** — Capture everything here first. Triage weekly.
- **[1-Projects/](1-Projects/)** — Short-term efforts with a defined goal and deadline.
- **[2-Areas/](2-Areas/)** — Ongoing responsibilities to maintain over time.
- **[3-Resources/](3-Resources/)** — Topics of interest and reference material.
- **[4-Archives/](4-Archives/)** — Inactive items from the other three categories.

## Workflow

1. **Capture** → drop notes into `Inbox/`
2. **Organize** → move into the right PARA folder by actionability
3. **Distill** → progressive summarization inside notes
4. **Express** → produce output from Projects

## Conventions

- One note per file, Markdown (`.md`)
- Filenames: `kebab-case.md`
- Link between notes with relative paths
- Archive completed projects — never delete
